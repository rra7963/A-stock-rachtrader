TradingAgents 中国 A 股迁移映射

范围：保持原有 Analyst、研究辩论、交易与风控链路；只替换已经存在工具槽位的数据来源。本文不记录凭据、内部正文或数据库连接信息。

已确认的原则
  • 不新增 china_a_stock 分析模式，不改变市场、新闻或基本面的推理框架。
  • 不把指数、行业指数、资金流、ETF 持仓等额外数据硬塞入原 Prompt；它们不是当前工具的替代品。
  • Market、Sentiment、News 和 Fundamentals Analyst 均可通过 CLI / selected_analysts 按需选择；未选择的节点不会创建。
  • 宏观 FRED 替换、全市场新闻、预测市场和 ETF 专项解释必须人工审核后再做。

原始分析链路

可选 Analyst（示意顺序）：Market → Sentiment → News → Fundamentals ↓ 已生成的 Analyst 报告 → Bull / Bear → Research Manager ↓ Trader → Risk debate → Portfolio Manager

运行时仅创建被选中的 Analyst，并按选择顺序串行执行；各自独立产出报告，最后由 Bull / Bear 统一使用。当前 A 股适配没有可用且已验证的 Sentiment 数据源，建议不选择 social。参见 GraphSetup、TradingAgentsGraph 与 CLI 选择。

明确不纳入当前适配

  • 指数、申万行业指数、个股资金流：原分析链路没有对应工具或 Prompt 槽位，不能当作“缺失替代品”。
  • get_prediction_markets：当前是 Polymarket 的全球事件隐含概率，不存在应被新闻或事件数据冒充的中国替代。
  • get_insider_transactions：尚未确认语义等价的 A 股来源。
  • ETF NAV、持仓、份额、资金流：它们不等于公司财务基本面；留待 ETF 专项分析。
